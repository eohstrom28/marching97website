## Update Timeline (after Exec Board transition)

### Winter break (ASAP)

* Contact page: update Exec info
* Execs page: update photos (+ alt text), names, and bios
* Join page: update Refrosh photos (+ alt text), names, and Join link (new interest form)

### Spring
* Schedule page: update game schedule and other mandatory events (like CMBF) when it comes out
    * Make sure to put stars next to mandatory events
* Media page: add photos from spring flames
* Documents page: update files and links after revisions are made

### Summer
* Rank pages: update Rank leader photos (+ alt text), bios, and rank descriptions with input from Rank Leaders (if there are different instruments or it's out-of-date)
* Documents: update booster club form

### Fall
* Rank pages: update rank photos (+ alt text) after band camp
* Home page (index): update silly official band photo, **update upcoming event and exec board announcements WEEKLY-ish**
    * Upcoming event examples: band camp, flames, and games
    * Exec board announcements examples: band camp, HBD, ABD, LeLaf, Lehigh Fest, recruitment form open, Giving Day (include donation link)
    * Give at least 2 weeks prior for major events, 1 week prior otherwise (put multiple events if this timeline overlaps by adding another paragraph with ```<p>Second Event</p>```)
* Media page: update the year and **add band camp photos + game/flame photos as they occur**

### Update as Needed
* History page: add major events to timeline, add photos (+ alt text)
* Director page: update photos, info, and add to Past Directors
